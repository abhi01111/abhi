### **1. What is the primary benefit of virtualization?**
- A) Increased power consumption
- B) Better resource utilization and flexibility
- C) Increased hardware requirements
- D) Decreased system security

**Answer**: B) Better resource utilization and flexibility  
**Explanation**: Virtualization allows multiple virtual machines to run on a single physical server, optimizing resource use and providing flexibility to scale resources based on demand.

---

### **2. Which type of hypervisor runs directly on hardware?**
- A) Type 1 Hypervisor
- B) Type 2 Hypervisor
- C) Host OS
- D) Virtual Machine

**Answer**: A) Type 1 Hypervisor  
**Explanation**: Type 1 hypervisors (bare-metal hypervisors) run directly on hardware, managing virtual machines without the need for an underlying operating system (e.g., VMware ESXi, Microsoft Hyper-V).

---

### **3. What is para-virtualization?**
- A) Virtualization that uses hardware support
- B) Virtualization where the guest OS interacts directly with the hypervisor
- C) Virtualization without the use of hypervisors
- D) Virtualization based on containerization

**Answer**: B) Virtualization where the guest OS interacts directly with the hypervisor  
**Explanation**: In para-virtualization, the guest operating system is aware of the virtualized environment and can communicate directly with the hypervisor to optimize performance.
