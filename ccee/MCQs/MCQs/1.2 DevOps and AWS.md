### **Essential Theory to Remember for DevOps**

#### **1. Agile and Lean in DevOps**

- **Agile Methodology**: Iterative development focused on adaptability to changing requirements. Key methods include **Scrum (sprints and roles)** and **Kanban (continuous flow and visualisation)**.
- **Lean**: Focuses on reducing waste, optimising processes, and continuous improvement.

#### **2. DevOps Fundamentals**

- **DevOps Goal**: Bridge the gap between development and operations for faster, more reliable software delivery.
- **CAMS Model**: Culture, Automation, Measurement, Sharing – foundational to DevOps success.
- **Kaizen**: Continuous improvement principle applied in DevOps.

#### **3. CI/CD Pipelines**

- **Continuous Integration (CI)**: Automating code integration and testing.
- **Continuous Delivery/Deployment (CD)**: Automating software deployment to production.
- **Jenkins**: Popular CI/CD tool for automating build, test, and deploy processes.

#### **4. Containerisation and Orchestration**

- **Containerisation**: Packages applications and dependencies into portable containers using tools like **Docker**.
- **Kubernetes**: Manages and orchestrates containerised applications across clusters, ensuring scalability, load balancing, and self-healing.
- **Docker Swarm**: Docker’s built-in orchestration tool for simpler setups.
- **Kubernetes Components**:
    - **Pod**: Smallest deployable unit containing one or more containers.
    - **Controller**: Maintains the desired state of the cluster.
    - **API Server**: Entry point for managing the cluster.

#### **5. Infrastructure as Code (IaC)**

- **Definition**: Automating infrastructure management using code.
- **Tools**:
    - **Terraform**: Deploys and manages infrastructure via declarative configuration files (HCL).
    - **Ansible**: Automates configuration management using YAML playbooks.
- **Terraform Modules**: Reusable components for consistent configurations.
- **Ansible Roles**: Structured organisation of playbooks for reusability.

#### **6. Key DevOps Tools**

- **GitHub**: Version control platform for collaboration on code repositories. Key actions include **clone**, **commit**, **push**, and **pull requests**.
- **Jenkins**: Automates CI/CD workflows, including builds, tests, and deployments.
- **Nagios**: Monitors infrastructure performance and availability.
- **Prometheus**: Cloud-native monitoring tool for time-series data.

#### **7. Automation Concepts**

- **Immutable Infrastructure**: Deploying unchangeable components, reducing drift between environments.
- **Auto-Scaling**: Dynamically adjusting resources based on workload demands.
- **Auto-Healing**: Restarting failed containers or nodes automatically.

#### **8. Cloud and DevOps Integration**

- **Cloud Services**: Use AWS for infrastructure (EC2), storage (S3), and serverless computing (Lambda).
- **IAM (Identity and Access Management)**: Manages secure access to cloud resources.
- **VPC (Virtual Private Cloud)**: Isolates resources in a private network for enhanced security.
