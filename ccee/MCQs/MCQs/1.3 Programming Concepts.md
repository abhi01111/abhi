#### **Session 1: Concepts of Databases, Tables, and Schemas**

1. **Theory Summary**
    
    - **Databases**: Organised collections of data stored and accessed electronically.
        - Example: A database for a library stores books, members, and loans.
    - **Tables**: Logical structures within databases used to store rows (records) and columns (attributes).
        - Example: A table `Books` may have columns like `BookID`, `Title`, `Author`.
    - **Schemas**: Blueprints of the database structure, including tables, views, and relationships.
    - **Creating Databases**: Use `CREATE DATABASE` to define a new database.
    - **Dropping Databases**: Use `DROP DATABASE` to delete an existing database.
    
    **Syntax for Creating and Dropping Databases**:
    
    ```sql
    -- Create a new database
    CREATE DATABASE LibraryDB;
    
    -- Drop an existing database
    DROP DATABASE LibraryDB;
    ```
    
    **Best Practices for Naming Databases**:
    
    - Use meaningful names (`LibraryDB`, not `DB1`).
    - Avoid special characters or spaces.
    - Follow consistent casing (`CamelCase` or `snake_case`).

### **MySQL Sessions 2 & 3: SELECT, WHERE, ORDER BY, and JOIN Operations**

#### **Theory Summary**

1. **SELECT Statement**:
    
    - Fetches data from a database table.
    - Syntax:
        
        ```sql
        SELECT column1, column2 FROM table_name;
        ```
        
    - Example:
        
        ```sql
        SELECT Name, Age FROM Employees;
        ```
        
2. **WHERE Clause**:
    
    - Filters data based on specific conditions.
    - Syntax:
        
        ```sql
        SELECT * FROM table_name WHERE condition;
        ```
        
    - Example:
        
        ```sql
        SELECT * FROM Employees WHERE Age > 30;
        ```
        
3. **ORDER BY Clause**:
    
    - Sorts the results in ascending (`ASC`) or descending (`DESC`) order.
    - Syntax:
        
        ```sql
        SELECT * FROM table_name ORDER BY column1 [ASC|DESC];
        ```
        
    - Example:
        
        ```sql
        SELECT * FROM Employees ORDER BY Age DESC;
        ```
        
4. **JOIN Operations**:
    
    - Combines data from multiple tables based on a related column.
        
    - Types:
        
        - **INNER JOIN**: Returns records with matching values in both tables.
        - **LEFT JOIN**: Returns all records from the left table and matched records from the right table.
        - **RIGHT JOIN**: Returns all records from the right table and matched records from the left table.
        - **FULL OUTER JOIN**: Returns all records when there is a match in either table.
    - Syntax (INNER JOIN):
        
        ```sql
        SELECT table1.column1, table2.column2 
        FROM table1 
        INNER JOIN table2 
        ON table1.common_column = table2.common_column;
        ```
        
    - Example:
        
        ```sql
        SELECT Employees.Name, Departments.DeptName
        FROM Employees
        INNER JOIN Departments
        ON Employees.DeptID = Departments.DeptID;
        ```

### **MySQL Sessions 4 & 5: Aggregate Functions, GROUP BY, HAVING, and Subqueries**

#### **Theory Summary**

1. **Aggregate Functions**:
    
    - Perform calculations on multiple rows of data.
    - Common functions:
        - **SUM()**: Returns the total sum of a numeric column.
        - **COUNT()**: Returns the number of rows.
        - **AVG()**: Returns the average value.
        - **MAX()**: Returns the maximum value.
        - **MIN()**: Returns the minimum value.
    - Example:
        
        ```sql
        SELECT SUM(Salary), AVG(Salary) FROM Employees;
        ```
        
2. **GROUP BY Clause**:
    
    - Groups rows that have the same values into summary rows.
    - Syntax:
        
        ```sql
        SELECT column, aggregate_function(column)
        FROM table_name
        GROUP BY column;
        ```
        
    - Example:
        
        ```sql
        SELECT Department, COUNT(*)
        FROM Employees
        GROUP BY Department;
        ```
        
3. **HAVING Clause**:
    
    - Filters grouped data (used with GROUP BY).
    - Syntax:
        
        ```sql
        SELECT column, aggregate_function(column)
        FROM table_name
        GROUP BY column
        HAVING condition;
        ```
        
    - Example:
        
        ```sql
        SELECT Department, AVG(Salary)
        FROM Employees
        GROUP BY Department
        HAVING AVG(Salary) > 50000;
        ```
        
4. **Subqueries**:
    
    - A query nested within another query.
    - Types:
        - **Scalar Subquery**: Returns a single value.
        - **Row Subquery**: Returns a single row.
        - **Column Subquery**: Returns a single column.
        - **Correlated Subquery**: Uses values from the outer query.
    - Example:
        
        ```sql
        SELECT Name
        FROM Employees
        WHERE Salary > (SELECT AVG(Salary) FROM Employees);
        ```

### **Python Sessions 7 & 8: Dictionaries, Lists, and File Handling**

#### **Theory Summary**

1. **Dictionaries**:
    
    - Key-value pairs used to store data.
    - Syntax:
        
        ```python
        my_dict = {"name": "Alice", "age": 25}
        ```
        
    - Access elements:
        
        ```python
        print(my_dict["name"])  # Output: Alice
        ```
        
    - Modify and delete:
        
        ```python
        my_dict["age"] = 26
        del my_dict["name"]
        ```
        
2. **Lists**:
    
    - Ordered collections of items.
    - Syntax:
        
        ```python
        my_list = [1, 2, 3, 4]
        ```
        
    - Add elements:
        
        ```python
        my_list.append(5)
        ```
        
    - Delete elements:
        
        ```python
        my_list.remove(2)
        ```
        
    - Searching:
        
        ```python
        if 3 in my_list:
            print("Found")
        ```
        
3. **File Handling**:
    
    - Reading and writing files.
    - Open a file:
        
        ```python
        file = open("example.txt", "r")  # Modes: "r", "w", "a", "rb"
        ```
        
    - Read content:
        
        ```python
        content = file.read()
        ```
        
    - Write content:
        
        ```python
        file = open("example.txt", "w")
        file.write("Hello, File!")
        ```
        
    - Always close files:
        
        ```python
        file.close()
        ```

### **Python Session 11: Regular Expressions and Functional Programming**

#### **Theory Summary**

1. **Regular Expressions (Regex)**:
    
    - Patterns for matching text.
    - Common functions in the `re` module:
        - **`re.search()`**: Finds a match anywhere in the string.
            
            ```python
            import re
            match = re.search(r"\d+", "Order123")
            print(match.group())  # Output: 123
            ```
            
        - **`re.match()`**: Matches only at the beginning of the string.
        - **`re.findall()`**: Returns all matches as a list.
        - **`re.sub()`**: Replaces matches with a specified string.
            
            ```python
            text = re.sub(r"\d", "#", "A1B2C3")
            print(text)  # Output: A#B#C#
            ```
            
2. **Functional Programming**:
    
    - **`map()`**: Applies a function to each item in an iterable.
        
        ```python
        nums = [1, 2, 3]
        squared = list(map(lambda x: x**2, nums))
        print(squared)  # Output: [1, 4, 9]
        ```
        
    - **`filter()`**: Filters items based on a condition.
        
        ```python
        even_nums = list(filter(lambda x: x % 2 == 0, nums))
        print(even_nums)  # Output: [2]
        ```
        
    - **`reduce()`** (from `functools`): Reduces an iterable to a single value.
        
        ```python
        from functools import reduce
        total = reduce(lambda x, y: x + y, nums)
        print(total)  # Output: 6
        ```

### **Session 16: Exploit Development Techniques**

#### **Theory Summary**

1. **Exploit Development**:
    
    - Process of identifying and leveraging software vulnerabilities.
    - Common vulnerabilities include:
        - Buffer overflows
        - SQL injection
        - Cross-site scripting (XSS)
2. **Writing Exploits**:
    
    - Exploits are scripts or programs that use vulnerabilities.
    - Example: Writing an exploit for a buffer overflow.
        
        ```python
        payload = "A" * 256  # Overflowing the buffer
        print(payload)
        ```
        
3. **Socket Programming in Exploits**:
    
    - Socket programming is used to send payloads to the target system.
    - Example:
        
        ```python
        import socket
        s = socket.socket()
        s.connect(("victim_ip", 80))
        s.send(b"Malicious payload")
        ```
        
4. **Common Tools**:
    
    - Metasploit Framework: A widely used tool for exploitation.
    - Debuggers: Tools like GDB or Immunity Debugger help understand vulnerabilities.
