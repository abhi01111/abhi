#### **Theory Summary**

**OWASP Top 10 – 2021**

- Highlights the most critical web application security risks.
- Categories include Injection, Cryptographic Failures, Broken Access Control, and more.
- Aims to educate developers and security teams on prevalent vulnerabilities.

**Injection and Inclusion**

- Injection attacks involve executing unintended commands through user input.
- Common types: SQL Injection, Command Injection, and File Inclusion (LFI/RFI).
- Defence: Parameterised queries, input sanitisation, and least privilege for database access.

**Cross-Site Scripting (XSS)**

- XSS involves injecting malicious scripts into web pages viewed by other users.
- Types: Stored, Reflected, and DOM-based XSS.
- Consequences include credential theft and session hijacking.
- Preventive Measures: Input validation, output encoding, and using security headers (e.g., Content Security Policy).

**Injection in Stored Procedures**

- Vulnerabilities arise when stored procedures do not properly sanitise input.
- Example: SQL Injection exploiting stored procedure parameters.
- Mitigation: Using parameterised procedures and avoiding dynamic queries.

- Techniques: Whitelisting, blacklisting, and using regular expressions.

**Access Control:**

- Restricts access to resources based on permissions.
- Types: Mandatory, Discretionary, and Role-Based Access Control.

**DAST (Dynamic Application Security Testing):**

- Tests applications during runtime to identify vulnerabilities like SQL Injection and XSS.
- Focuses on how the application behaves with malicious inputs.

**Burp Suite:**

- A comprehensive tool for vulnerability assessment and web application security testing.
- Features include request interception, automated vulnerability scanning, and fuzzing.

**Browser Security Tools:**

- Add-ons like JSGuard detect and block suspicious or malicious webpages.
- Enhance user security by identifying potential threats in real-time.

**Case Study on Web Application Frameworks:**

- Focuses on analysing the security features of frameworks to identify their strengths and weaknesses.
- Examples include Django, Ruby on Rails, and Spring.

**Integrating SAST and DAST:**

- Combining these methods ensures both static and runtime vulnerabilities are covered.
- Provides a more robust security testing approach.

### **Theory Summary**

**Mobile Malware:**

- **Definition:** Malicious software designed to exploit vulnerabilities in mobile devices.
- **Examples:** Banking Trojans, adware, ransomware.

**Session Hijacking:**

- Exploits active sessions to gain unauthorised access.
- Techniques: Session spoofing and ID capturing.

**Countermeasures:**

- Use secure cookies with HTTPS.
- Regularly monitor sessions and implement session expiration policies.
- Avoid insecure public Wi-Fi for sensitive transactions.

**Common Attacks:**

- Reverse shells enable remote control of devices.
- Malware families target specific functionalities like banking or file encryption.
