In security concept what is cryptography ? types ? where they are used ?
	🔐 What is Cryptography in Security?
		- Cryptography is the science and art of securing information by transforming it into an unreadable format so that only authorized parties can read or process it.
		- It protects data confidentiality, integrity, authenticity, and non-repudiation.
	
	🧠 Key Concepts in Cryptography:
		|-----------------------------------------------------------------------------|
		| Term           | Meaning                                                    |
		| -------------- | ---------------------------------------------------------- |
		|   Plaintext    | Original readable data                                     |
		|   Ciphertext   | Encrypted unreadable data                                  |
		|   Encryption   | Converting plaintext to ciphertext                         |
		|   Decryption   | Converting ciphertext back to plaintext                    |
		|   Key          | A value used with an algorithm to encrypt/decrypt data     |
		|   Algorithm    | Mathematical formula used to perform encryption/decryption |
		|-----------------------------------------------------------------------------|
	
	🧩 Types of Cryptography:
		1. Symmetric Key Cryptography (Secret Key)
			- Same key is used for both encryption and decryption.
			- Fast but key must be shared securely.
			- Examples: AES, DES, Blowfish, RC4
			- Use Cases: File encryption, secure communication in VPNs

		2. Asymmetric Key Cryptography (Public Key)
			- Uses a public key to encrypt and a private key to decrypt.
			- Secure key exchange, but slower than symmetric.
			- Examples: RSA, ECC, ElGamal
			- Use Cases: SSL/TLS, digital signatures, email encryption (e.g., PGP)
			
	✅ Benefits of Cryptography:
		- Confidentiality – Only intended parties can access the data.
		- Integrity – Data hasn’t been changed.
		- Authentication – Confirms identity of sender.
		- Non-repudiation – Prevents denial of a valid action (via digital signatures).
		
	📌 Where Cryptography is Used:
		|-------------------------------------------------------------------------|
		| Domain                | Usage Example                                   |
		| --------------------- | ----------------------------------------------- |
		|   Web Security        | HTTPS uses TLS with RSA/AES for secure browsing |
		|   Email               | PGP, S/MIME to encrypt email messages           |
		|   File Storage        | Encrypting files with AES                       |
		|   Banking & Finance   | Secure transactions, OTP, credit card data      |
		|   Authentication      | Passwords hashed and stored securely            |
		|   Blockchain/Crypto   | Bitcoin uses ECC and SHA-256                    |
		|   VPNs                | Secure tunneling with encryption                |
		|-------------------------------------------------------------------------|

IDS & IPS
	🔎 IDS (Intrusion Detection System)
		- It detects attacks but does not block them.
		
		✅ Key Features:
			- Monitors network or system traffic for suspicious activity.
			- Alerts admin if an attack is detected.
			- Works in passive mode.
		
		🔧 Types of IDS:
			- NIDS – Network-based IDS (e.g., Snort)
			- HIDS – Host-based IDS (e.g., OSSEC)
		
		📍 Use Case:
			- Detecting port scans, malware signatures, policy violations.
		
	🛡️ IPS (Intrusion Prevention System)
		-It detects and blocks attacks in real-time.
		
		✅ Key Features:
			- Monitors and actively blocks malicious traffic.
			- Can drop packets, reset connections, or quarantine systems.
			- Works inline with the traffic flow.
		
		📍 Use Case:
			- Blocking brute-force login attempts, DoS attacks, and malware.
		
		🧠 Key Differences:
			|---------------------------------------------------------------------------------------------------|
			| Feature               | IDS                             | IPS                                     |
			| --------------------- | ------------------------------- | --------------------------------------- |
			|   Full Form           | Intrusion Detection System      | Intrusion Prevention System             |
			|   Mode                | Passive (only alerts)           | Active (detects & blocks)               |
			|   Traffic Placement   | Out-of-band (monitor only)      | Inline (between source and destination) |
			|   Response            | Alerts admin                    | Takes action (block, reset, etc.)       |
			|   False Positives     | Generates alerts                | May block legitimate traffic if wrong   |
			|   Use in Industry     | Audit, analysis, SOC monitoring | Real-time protection for networks       |
			|---------------------------------------------------------------------------------------------------|

What is CIA ? explain with example ?
	🧱 CIA Stands For:
		|--------------------------------------------------------------------|
		| Term                    | Meaning                                  |
		| ----------------------- | ---------------------------------------- |
		|   C   – Confidentiality | Protecting data from unauthorized access |
		|   I   – Integrity       | Ensuring data is accurate and unaltered  |
		|   A   – Availability    | Ensuring systems and data are accessible |
		|--------------------------------------------------------------------|
		
	✅ 1. Confidentiality
		- Ensures only authorized users can access sensitive data.
			🔒 How it works:
				- Encrypt data
				- Use strong passwords
				- Implement access control
			📌 Example:
				- Your online banking details are encrypted so that only you (authorized user) can see the balance and transaction history.
	✅ 2. Integrity
		- Ensures data is not changed by unauthorized users or during transmission.
			🔧 How it works:
				- Use hash functions (e.g., SHA-256)
				- Use digital signatures
				- Version control and checksums
			📌 Example:	
				- If someone changes a transaction amount in a bank's database, the system detects a hash mismatch, flagging a possible data integrity issue.
	✅ 3. Availability
		- Ensures authorized users can access information and services when needed.
			⚙️ How it works:
				- Use backups and failover systems
				- Protect against DDoS attacks
				- Maintain uptime with load balancing
			📌 Example:
				- You can access your email or cloud storage 24/7 because the provider ensures availability with redundant servers and disaster recovery mechanisms.	
	
	🧠 Real-World Example (CIA Applied Together):
		📲 WhatsApp Communication:
			- Confidentiality: Uses end-to-end encryption to prevent others from reading your messages.
			- Integrity: If a message is tampered with in transit, it’s rejected or flagged.
			- Availability: WhatsApp uses multiple data centers to ensure the app works anytime worldwide.

What is Firewall ? what are its types ?
	🔥 What is a Firewall in Cybersecurity?
		- A firewall is a network security device (hardware or software) that monitors and controls incoming and outgoing 
			network traffic based on predefined security rules.
		- Acts as a barrier between a trusted internal network and untrusted external networks (like the internet).
		- Blocks or allows traffic based on rules (IP, port, protocol, etc.).
		- Prevents unauthorized access, malware, and hacking attempts.
		
	🧱 Types of Firewalls:
		1. Packet-Filtering Firewall
			- Works at the network layer (Layer 3).
			- Checks source/destination IP address, port, and protocol.
			- Does not inspect the actual content of packets.
			
			📌 Use Case: Small routers or edge devices to allow/block basic traffic.
		
		2. Stateful Inspection Firewall
			- Tracks the state of connections (TCP sessions).
			- Only allows packets that are part of an established session.
			- More secure than packet filtering.
			
			📌 Use Case: Enterprise firewalls that allow return traffic from legitimate requests.

		3. Application-Level Gateway (Proxy Firewall)
			- Works at the application layer (Layer 7).
			- Intercepts and inspects traffic (e.g., HTTP, FTP).
			- Can filter based on content, not just port/IP.

			📌 Use Case: Web proxy server that filters websites or scans for malware in HTTP/FTP traffic.
		
		4. Cloud Firewall (Firewall-as-a-Service)
			- Hosted in the cloud, protects cloud infrastructure.
			- Often integrated with cloud providers like AWS, Azure, GCP.

			📌 Use Case: Securing VMs, containers, or serverless apps in the cloud.

			|----------------------------------------------------------------------------------------------------------------|
			| Type                        | Layer       | Key Feature                       | Example                        |
			| --------------------------- | ----------- | --------------------------------- | ------------------------------ |
			| Packet-Filtering            | Network     | Filters by IP, Port, Protocol     | Cisco ACLs                     |
			| Stateful Inspection         | Transport   | Tracks connection state           | pfSense                        |
			| Proxy (Application Gateway) | Application | Inspects application data         | Squid Proxy                    |
			| Next-Gen Firewall (NGFW)    | All layers  | Deep inspection, IPS, App control | Palo Alto, Fortinet            |
			| Host-Based Firewall         | Host level  | Protects individual device        | Windows Firewall               |
			| Cloud Firewall              | Cloud Infra | Protects cloud resources          | AWS Security Groups, Azure NSG |
			|----------------------------------------------------------------------------------------------------------------|

Explain CSRF ? how to prevent it ?
	🛡️ What is CSRF (Cross-Site Request Forgery)?
		- CSRF is a type of web security vulnerability where an attacker tricks a user into performing unintended actions 
			on a web application where the user is authenticated.
	
	🧠 How CSRF Works:
		- User is logged in to a trusted website (e.g., banking site).
		- Attacker sends a malicious link or script (via email, image, iframe, etc.).
		- If user clicks it while still logged in, the browser sends the request with stored cookies/session.
		- The server trusts the request and performs the action (like transferring money).
	
	✅ How to Prevent CSRF Attacks
		|---------------------------------------------------------------------------|
		| Prevention Method         | Description                                   |
		| ------------------------- | --------------------------------------------- |
		|   CSRF Tokens             | Unique per request/form, verified server-side |
		|   SameSite Cookies        | Prevents automatic cross-site cookie sending  |
		|   Double Submit Cookies   | Token in both cookie and header               |
		|   Use POST/PUT            | Avoid state-changing GET requests             |
		|   Token Auth (JWT)        | Don’t rely on browser-managed cookies         |
		|---------------------------------------------------------------------------|
